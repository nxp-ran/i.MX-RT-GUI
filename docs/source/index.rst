i.MX RT GUI
===========

从点亮屏幕到高性能 GUI，本系列沿着 i.MX RT 的完整像素数据路径展开：
屏幕接口、显示控制器、存储系统、PXP/GPU 与 LVGL。

建议先阅读 :doc:`系列总纲 <imxrt-gui/README>`。
点击正文顶部的 ``English`` 按钮，可以阅读当前页面的完整英文版。

.. note::

   系列规划为 24 篇，目前已提供总纲及前 4 篇的中英文正文。
   理论说明与计算示例均明确区别于板卡实测。
