# 第 13 篇：认识 PXP——它能加速什么，不能加速什么？

> 系列：[i.MX RT 图形系统实战](README.md)
>
> 上一篇：[Cache、MPU 与 DMA 一致性](12-cache-mpu-dma.md)
>
> 下一篇：[PXP 实战——从单次处理到异步流水线](14-pxp-pipeline.md)
>
> 本篇目标：按数据路径理解 PXP，区分硬件、驱动和 LVGL 后端能力。参考公开 NXP 驱动与 LVGL 9.2.0，不声称全部 i.MX RT 具有同样 IP。

## 1. PXP 是像素处理流水线

PXP 的工作对象是像素数据，不是控件和页面。

一项工作可以概括为：

```text
源图像/背景 -> 受支持的转换、混合或变换 -> 目标图像
```

CPU 配置输入、输出和操作，PXP 执行内存读写，完成后软件把结果交给下一消费者。

PXP 既不是显示扫描接口，也不替代 LVGL 的事件、布局和无效区域管理。

## 2. Process Surface、Alpha Surface 与 Output

在常见 PXP 编程模型中：

| 路径 | 主要含义 | 核对内容 |
| --- | --- | --- |
| PS / Process Surface | 主图像或背景处理路径 | 格式、尺寸、位置、缩放、颜色转换 |
| AS / Alpha Surface | 覆盖或混合路径 | 像素 Alpha、全局 Alpha、颜色键 |
| Output | 结果写入 | 地址、pitch、格式、尺寸、可达性 |

这些名称描述具体路径，不能推出任意操作都能在任意输入上组合。

源格式和输出格式集合也可能不同。驱动某个枚举存在，不代表当前芯片条件分支允许使用它。

不同 PXP 版本还可能改变路由、寄存器或处理单元。以实际 IP 图和 SDK 为准。

## 3. 几类常见需求

| 需求 | PXP 的可能用途 | 需要确认 |
| --- | --- | --- |
| 图片搬运 | 输出到另一缓冲 | pitch、重叠、格式 |
| 格式转换 | 将可支持源转成显示格式 | 输入/输出组合与颜色配置 |
| Alpha 混合 | 前景覆盖背景 | Alpha 模式和计算路径 |
| 缩放 | 调整 PS 等支持路径尺寸 | 比例、滤波、边界与版本限制 |
| 旋转/翻转 | 图像方向调整 | 支持角度、路径与尺寸关系 |
| 颜色键/LUT | 特定像素处理 | 目标版本是否支持 |

列表是功能核对方向，不是每个型号的保证。

圆角、任意角度矢量路径、文字排版等 GUI 任务，不应自动当作一个 PXP 操作。

## 4. 两种不同的“支持”

硬件能通过多次操作实现一种效果，不代表 LVGL 后端愿意把它作为单项任务接收。

在 LVGL 9.2.0 的 PXP 后端中，可以看到：

- 简单矩形填充要求没有圆角和渐变。
- 图像和图层检查源/目标格式及对齐。
- 旋转检查 90 度倍数。
- 一些变换与透明度、重着色组合不会被接收。
- 该后端的变换路径还检查特定尺寸对齐。

这些是**该版本后端的限制**，不能直接写成所有 PXP 硬件的完整规格。

反过来，用户自己写两阶段缩放混合代码，也不能假定 LVGL 会自动使用它。

## 5. 操作描述至少包含哪些信息？

| 项目 | 为什么需要 |
| --- | --- |
| 源、背景和目标地址 | 决定实际读写 |
| 格式和字节/通道顺序 | 决定像素解释 |
| 宽高和 pitch | 决定区域与行间距 |
| 输入位置、输出位置与裁剪 | 决定画面坐标 |
| Alpha 与颜色转换 | 决定结果语义 |
| 旋转/缩放参数 | 决定输出尺寸和边界 |
| 缓存属性与拥有者 | 决定可见性和生命周期 |

`width` 和 `pitch` 的单位不同。不能把像素数直接填写到 `pitchBytes`。

输出缓冲还要容纳变换后的布局。90 度旋转后宽高交换，行跨度也要重新计算；按原尺寸分配可能越界。

## 6. 不要默认输入输出可以原地重叠

不同硬件路径的读取和写入顺序未必像 `memmove`。

除非目标文档明确允许，先用不重叠缓冲建立基线。

背景读取、前景读取和目标写入可能同时发生。对目标做部分更新时，还要明确旧背景是否需要保留。

一个源缓冲被 PXP 读取期间，CPU、GUI 或另一个 DMA 不应修改它。

## 7. 哪些配置容易残留？

重复使用一个 PXP 实例时，前一次工作可能设置了：

- CSC 颜色转换。
- Alpha 或颜色键。
- 旋转、翻转、缩放。
- 路由、裁剪与输出格式。

下一次工作必须建立完整、明确的有效状态。不能只更新地址就希望其他配置自动回到默认。

使用 SDK 的重置与配置流程，但也核对重置对中断、时钟和共享调用者的影响。

如果 LVGL 管理同一个实例，应用不应在另一任务随意重置它。

## 8. 用一组独立操作认识平台

| 操作 | 输入图案 | 验证 |
| --- | --- | --- |
| 无效果复制 | 彩色四角与行标记 | 内容、pitch、边界 |
| 格式转换 | 不同强度 RGB | 通道、量化 |
| 混合 | 固定前景与背景 | Alpha 为 0、中间值、255 |
| 旋转 | 非对称标记 | 方向、宽高、裁剪 |
| 缩放 | 网格与边界 | 比例、滤波与边缘 |

先检查结果，再计时。对缩放和混合，应明确参考舍入及容差，不把不同滤波输出当作“同画质性能比较”。

## 9. 小结

PXP 适合把受支持的像素处理从 CPU 转移到硬件，但必须核对输入路径、格式、组合、尺寸及软件适配。
